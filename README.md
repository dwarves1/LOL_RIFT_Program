# LOL RIFT Program

2~16개 팀의 리그전과 토너먼트를 반복 운영하기 위한 모바일 우선 대회 관리 웹사이트입니다.

## 주요 기능

- 대회 생성 시 2~16개 참가 팀 선택 및 팀별 선수 5명 등록
- 팀 간 경기 수에 따른 리그 대진 자동 생성
- 5팀은 지정 패자부활 대진, 그 외 팀 수는 부전승을 포함한 싱글 엘리미네이션 대진 생성
- 운영자의 승리팀 선택 및 다음 토너먼트 대진 자동 반영
- 동률 팀의 운영자 수동 시드 확정
- 관람자·운영자·관리자 권한 분리와 변경 이력
- 대회별 기본 포인트 지급, 승리팀 예측, 자동 정산, 누적 랭킹
- 모바일 일정·순위·대진표·운영 화면

포인트는 현금이나 상품으로 환전되지 않는 사이트 내 가상 포인트입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

데이터는 Cloudflare D1에 저장되며 스키마 변경 파일은 `drizzle/`에 보관됩니다.

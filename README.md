# LOL RIFT Program

반복해서 사용하는 리그 오브 레전드 대회 운영·모니터링 웹사이트입니다.

## 주요 기능

- 대회마다 2~16개 팀과 팀별 선수 5명 등록
- 팀 간 경기 수에 따른 리그 대진 자동 생성
- 운영자·관리자가 경기별 일정을 직접 입력·확정하고 승리팀 선택
- 리그 순위 확정 후 토너먼트 대진 생성 및 결과 자동 반영
- Google 로그인, 관리자·운영자·관람자 권한 분리, 변경 이력 기록
- 확정 일정에 한해 경기 시작 1시간 전까지 승리팀 예측
- 대회별 독립 포인트 지갑, 자동 정산, 대회 내 랭킹
- 모바일에 최적화된 일정·순위·대진표·운영 화면

포인트는 현금이나 상품으로 환전하지 않는 사이트 내부 가상 포인트입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

데이터는 Cloudflare D1에 저장되며 스키마 변경 파일은 `drizzle/`에 보관합니다.
